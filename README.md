**RS Phone** is a full-source FiveM roleplay smartphone from RealitySucksRP. It combines player communication, camera and video capture, persistent media, banking, social apps, maps, businesses and emergency services with a deployable Drone and Recon surveillance system.

> This standalone GitHub repository is a **public product showcase**, not a public release of the software source. Obtain the resource and its installation files from the [official Tebex package](https://reality-sucks-rp-webstore.tebex.io/package/7628037). Full source is subject to the included RealitySucksRP commercial license.

## Key features

| Category | Included features |
|---|---|
| Calls and messaging | Calls, video calling with picture-in-picture, contacts, individual/group messages, persistent chats and email |
| Social and community | Community/Chirp, news, marketplace, DarkMarket, Yellow Pages, media sharing and replies |
| Camera and Gallery | Photo and selfie modes, video recording, persistent photo/video library, wallpaper selection, sharing and deletion |
| Drone and Recon | Deployable micro cameras, vehicle-mounted camera options, controllable feeds, signal-range simulation, recovery and secure owner access |
| Phone hardware | Multiple handset frames and colors, portrait/landscape presentation, lock screen, wallpapers, icon themes and fonts |
| Banking and economy | Cash/bank balances, supported transactions, transfer histories, bills and business integration |
| World gameplay | GPS, interactive Maps, emergency/SOS tools, garages, houses, taxi, racing, weather and player stats |
| Extensibility | Framework and provider bridges, inventory adapters, optional server-resource integrations and documented APIs |

### Phone that works with the world

RS Phone's Recon layer gives players deployable micro surveillance cameras, vehicle-mounted camera options, remote feeds, configurable sharing permissions and a private map layer. Signal range and battery/routing rules are part of the gameplay. Standard phone functionality works independently of the recon system.

### Player customization

Select from multiple frame designs, finishes, icon themes and font styles. Use an updated lock screen, configurable wallpaper, portrait or landscape layout, live weather information and polished app transitions.

## Compatibility

- **Game:** FiveM GTA V Legacy and Enhanced; OneSync
- **Frameworks:** Qbox, QBCore, ESX and standalone fallback
- **Inventory:** ox_inventory and qb-inventory integrations
- **Resource manifest version from provided ZIP:** `4.15.5`
- **Core dependencies declared by supplied manifest:** `oxmysql`, `ox_lib` and `screencapture`, with OneSync enabled
- **Voice:** compatible live-voice resource required for voice calling
- **Optional integrations:** configured separately when the relevant economy, garage, housing, racing, dispatch or other provider is installed

The resource includes its own internal framework bridge. **No external `rs_bridge` dependency is required.**
